**Subsystem:** Quotations / Invoices / Gmail / Google Drive

## Operator decision

Commercial document files must be named from their document reference only.

## Quotation rule

- Use the exact quotation reference as the filename, for example `ST-20260731-01.pdf`.
- Do not use prefixes such as `Quotation -` or add customer names, status words or revision labels.
- If a newly issued updated quotation is created for the same customer in the same reference period, increment the sequence: `-02`, `-03`, and so on.
- Use the same filename in Gmail and Google Drive.

## Invoice rule

- Use the established invoice reference filename, normally `Invoice[Number].pdf` or `Faktura[Number].pdf`.
- Do not add customer names, dates, status words or revision labels.
- Use the same filename in Gmail and every Drive location.
