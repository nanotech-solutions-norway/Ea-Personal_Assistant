## Storage rule

- GitHub stores sanitized approved structured knowledge and version history.
- ChatGPT Project stores compact active knowledge summaries and working context.
- Custom GPT stores stable, sanitized knowledge only.
- Google Drive, Gmail, Calendar and Contacts store evidence and live operational material.

## Authority rule

Knowledge is not canonical until validated and approved. Pricing, warranty, delivery commitments, legal, tax, accounting, product claims, confidentiality rules and public claims remain PENDING_REVIEW unless explicitly approved.

The scheduled-email memory is canonical because it records explicit operator instructions and reconciles them with the current Ea source-authority framework. It does not activate Level 2 automation.
